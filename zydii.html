About Zydii

Zydii is the leading localized digital training solution that offers engaging and accessible learning experiences fostering transformative growth for businesses. Learners engage with a catalog of over 70 localized digital African courses, co-created with vetted, African instructors & experts.

Technologies used:

  • Laravel - The framework used in handing most of the backend processes
  • Livewire & Alpine - for building dynamic interfaces and reactive interfaces using server-side code
  • JavaScript - for client-side scripting and adding interactivity to web pages
  • AfricasTalking API - for sending SMS reminders and notifications to users
  • QuickBooks API - for creating invoices and viewing businesses payment history
  • Brevo API - for sending email notifications
  • MySQL & Redis - database for for storing and managing system data
